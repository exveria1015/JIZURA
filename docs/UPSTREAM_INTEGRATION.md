## 追加修正の要点

混在 LRC の例 `one\ntwo\n[00:00.10]A` で2行目を10秒に指定すると、単純に #30 と #31 を組み合わせた状態では開始時刻が `[0.4, 0.4, 0.1]` と逆行しました。次の LRC 時刻を自動行の上限にも使い、`[0, 0.05, 0.1]` に収まるよう修正しています。保存済みの手入力値は書き換えません。

文字制御では、すべてのレイアウトが共通の文字描画関数を通るという前提が成立していませんでした。Canvas を直接使う経路と、文字形状をタイルや点へ変換する経路にも非表示・差し替えを適用しました。中央を空けるモードでは両側へ設定を引き継ぎます。

文字起こしは、実行時のプロジェクトと音声に結果をひも付けます。初期化、プロジェクト読み込み、音声変更、結果の破棄後は古い進捗と結果を採用しません。タップ同期・動画書き出し中の実行と適用も防ぎます。指定ライブラリの言語未指定時の挙動が英語へのフォールバックだったため、「自動判定」を削除し、日本語／英語を選択する方式にしました。
